🎯 PROMPT DE CRÉATION - PATRIMOINE-COGNITIF.FR
CONTEXTE STRATÉGIQUE
Tu es un expert en développement web full-stack et en UX/UI design haut de gamme. Tu vas créer le site patrimoine-cognitif.fr, une plateforme d'autorité qui définit et promeut les concepts de "Patrimoine Cognitif" et "Testament Éthique Numérique".
Positionnement : Institutionnel, souverain, élégant, discret mais impactant. Cible : Family offices, notaires, familles fortunées, institutions européennes.
Ton concurrent : Mywie (trop émotionnel, trop commercial). Notre différence : sobriété, rigueur, souveraineté technologique, approche institutionnelle.
🎨 IDENTITÉ VISUELLE & DESIGN
Style recherché :
Luxe discret : Inspiré des banques privées suisses, family offices, institutions européennes
Palette :
Dominante : Noir profond (#0A0A0A), Gris anthracite (#1A1A1A)
Accents : Or vieilli (#C9A961) ou Cuivre (#B87333) pour la sophistication
Texte : Blanc cassé (#F5F5F5) pour la lisibilité
Secondaire : Bleu marine profond (#0F172A) pour la confiance institutionnelle
Typographie :
Titres : Playfair Display ou Cormorant Garamond (sérif élégant, institutionnel)
Corps : Inter ou Source Sans Pro (sans-serif moderne, lisible)
Hiérarchie stricte et espacée
Ambiance :
Minimalisme sophistiqué
Animations subtiles (fade-in, parallax léger)
Espaces blancs généreux (respiration)
Photographies : Abstraites, symboliques (arbres généalogiques stylisés, archives anciennes, coffres-forts, lumière tamisée)
Zéro élément "tech" criard : Pas de robots, de circuits, de néons
️ ARCHITECTURE TECHNIQUE
Stack recommandée :
Framework : Next.js 14+ (App Router) pour le SEO et les perfs
Styling : Tailwind CSS + Framer Motion pour les animations
CMS : Sanity.io ou Strapi (pour faciliter les mises à jour de contenu)
Hébergement : Vercel (performances) ou OVHcloud (souveraineté française)
SEO : next-seo, sitemap.xml, robots.txt optimisés
Analytics : Plausible ou Matomo (respect RGPD, pas de Google Analytics)
Contraintes techniques :
Score Lighthouse > 95 (perf, accessibilité, SEO, best practices)
Responsive parfait (mobile-first)
Accessibilité WCAG 2.1 AA
Temps de chargement < 2s
HTTPS obligatoire
Conformité RGPD stricte (cookie banner minimaliste)
